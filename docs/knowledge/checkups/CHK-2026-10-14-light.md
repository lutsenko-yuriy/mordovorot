### Unused functionality

- **Finding:** `BoardImpl.counter` is a public `var` that `resetGame`/`newGame`/`restoreState` reset to 0, but nothing in production ever increments or reads it. Its only readers are three tests (`BoardImplResetTest`, `BoardImplNewGameTest`, `BoardImplRestoreStateTest`) that assert the reset. GH-62 (move counter, in flight) will either repurpose it or replace it, so it shouldn't be removed under GH-62's feet.
- **Debt quadrant:** inadvertent × prudent
- **Disposition:** deferred — see ledger Open findings, deadline `2026-11-14`
- **Graduation candidate:** yes — an unused-declaration check (detekt `UnusedPrivateMember`/IntelliJ inspection run in CI) would flag write-only properties.

- **Finding:** `kotlinx-coroutines-test` is still a `testImplementation` dependency with zero imports in `src/test`. `build.gradle.kts` and ARCHITECTURE.md both record "adopt `runTest` or drop the dependency" as an open decision carried since GH-42 WU1, and nothing has settled it.
- **Debt quadrant:** deliberate × prudent
- **Disposition:** deferred — see ledger Open findings, deadline `2026-11-30`
- **Graduation candidate:** yes — a dependency-analysis plugin (e.g. `dependency-analysis-gradle-plugin`) reports unused declared dependencies.

### Glossary/naming drift

- **Finding:** `docs/GLOSSARY.md` has drifted from the code. (a) `Square side`'s code symbol is `SQUARE_SIDE`, which no longer exists; the code uses the `squareSide` property plus `BoardSize.MIN/MAX/DEFAULT`. (b) `Save file`'s symbol still reads "none yet — added by GH-6", but `SaveRepository`/`FileSaveRepository`/`SavedBoard` exist. (c) "solved state" is listed as an alias to avoid, yet `ViewModel.isSolved()`, the TUI code, and PRODUCT_SPEC all say "solved" throughout, so the alias table contradicts the codebase's actual vocabulary. (d) Established terms have no entry: input mode (`InputMode`), board size (`BoardSize`), startup restore prompt, toolbar, dialog, save info (`SaveInfo`). Not fixed inline because `docs/GLOSSARY.md` has an uncommitted GH-62 edit in the working tree that must not be swept into this commit.
- **Debt quadrant:** inadvertent × prudent
- **Disposition:** deferred — see ledger Open findings, deadline `2026-10-31`
- **Graduation candidate:** partially — a script could check that every backticked code symbol in the glossary's `Code symbol` column still resolves via grep in `src/main`. That would catch (a) and (b), but not (c) or (d).
