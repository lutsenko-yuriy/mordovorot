# GH-359: Research: should Mordovorot be listed in the app stores (Google Play, Apple App Store)?

## Notes

### 2026-11-27

- Scope (approved): Musts were the fees against "free tiers only", whether a Play Trusted Web Activity works on the sub-path hosting, Apple guideline 4.2, and how saves move between copies; the Shoulds (maintenance, alternatives) were surveyed in the same pass.
- Verified against official pages: the Play fee (US$25 one-time) and the personal-account closed test (12 testers, 14 days); the Digital Asset Links file must be at the domain root, so the project page `lutsenko-yuriy.github.io/mordovorot/` would need the user-site repository or a custom domain; Microsoft Store individual registration is free; Apple US$99 a year; itch.io takes HTML5 uploads with a 0% to 100% revenue share. Sources are inline in ADR-0008.
- Corrections to the first surveys: Chrome's TWA docs say the host app has no access to the web content's cookies or `localStorage` (sharing storage with Chrome is likely, not stated); PWABuilder's docs still show a US$19 Microsoft fee that Microsoft's own page has dropped.
- Still unverified: Samsung Galaxy Store and Amazon Appstore PWA acceptance (hosts blocked), PWABuilder being free in so many words (it is MIT-licensed), PWABuilder's last commit date, a Microsoft Store package with a sub-path `start_url`, and a literal statement that a Home Screen copy's storage is separate from Safari's.
- The surveys' first pass could read almost nothing: the research hosts (developer.chrome.com, support.google.com, web.dev, learn.microsoft.com, docs.pwabuilder.com, itch.io, webkit.org) were not on the Default environment's allowlist; they were added, with the owner's approval, after the first pass.
- Decision (owner): no store listing for now, and not even itch.io; the rest is decided later. Recorded as ADR-0008.
