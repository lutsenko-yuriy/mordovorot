# GH-79: Remove console mode

## Notes

## Debrief summary

### 2026-10-15

**What went well**
- The codebase shrank (~3,400 lines removed vs ~900 added, mostly TUI ports of the old console scenarios) - the user liked seeing it get smaller rather than bigger.
- The real-terminal check passed and the code was approved without rework beyond one audit fix.

**What was hard or surprising**
- Plan decision D2 ("messages go to stderr") didn't consider visibility: the failed-switch notice is raised mid-session, where the full-screen TUI covers stderr. The audit caught it; the fix shows the notice on the rebuilt TUI's status line via `View.play(notice)`.

**What to change**
- `plan` now asks, for any user-facing message, whether the user can actually see it where it's routed while the active UI runs. Kept light - the focus is moving to KMP soon.
