# GH-109: Upgrade Kotlin to the latest stable 2.x

## Notes

## Debrief summary

### 2026-10-17

**What went well**
- The plan trial-built the upgrade in a scratch copy, so implementation had no surprises: Kotlin 2.4.21, coroutines 1.11.0 and Gradle 9.7.1 forced no production code changes, and 586 tests passed before and after.
- The user confirmed the game still starts and can be finished; a pty smoke test showed the board, `Moves: 0`, Mordie's line and the Exit dialog.
- The audit's suggestions (wrapper `distributionSha256Sum`, ignoring `.kotlin/`) were small and fixed in the same round.

**What was hard or surprising**
- The kotlinx-coroutines version was written out in three build files kept in step only by a comment. The plan didn't spot it; review did, which added `gradle/libs.versions.toml` and a second review round.

**What to change**
- `skills/design/plan/SKILL.md`: dependency and tool-version updates get their own WU, verified by the full test suite plus any scenario suite, and that WU first consolidates any version written in more than one place.
- Same rule proposed upstream as YAB #35: https://github.com/lutsenko-yuriy/yuriys-agentic-boyz/issues/35
