- 2026-11-18: For the debrief: while reviewing the autosave WU1, the user observed that a lot of things are slowly piling up (WebGame at ~300 lines, a 19-parameter GameViewModelImpl, shared mutable session objects, a feature touching viewmodel + web + Main + many scenarios) and that we may need a layered, DDD-style architecture. ## Debrief summary

### 2026-11-18

**What went well**
- Quicker than expected: two WUs (scenarios, then one production WU) where four and several hours were expected.
