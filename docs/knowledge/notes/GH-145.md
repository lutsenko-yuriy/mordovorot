# GH-145: Web on touch screens: double-tap zooms in and long-press selects text

## Notes

## Debrief summary

### 2026-10-24

**What went well**
- Went really well overall. The cause was readable straight from the CSS (only `.tile` opted out of
  touch defaults), so the fix was a few lines with red-first tests in `TouchGesturesTest`.
- The user's Safari check confirmed it on a real iPhone.

**What was hard or surprising**
- Headless Chromium doesn't double-tap-zoom a `width=device-width` page with or without the fix,
  so the zoom half could only be verified on a real device.
- Session setup in a fresh cloud container took longer than the fix: the onboarding gate blocked
  writes until `/onboard` marked the clone, Maven Central answered intermittently through the
  session proxy (worked around with a local init script pointing Gradle at Google's mirror), and
  the build's Java 17 toolchain had to be installed.

**What to change**
- No change to this repo's workflow. Cloud-session setup is tracked as a YAB research ticket
  (yab-dev #26); meanwhile the user may reuse sessions, compacting context regularly.
- The page-fits-the-screen request raised during this ticket became its own ticket (GH-147).
