## Debrief summary

### 2026-10-18

**What went well**
- The user rated the ticket well overall; the web interface was above their expectations (look, drag feel, animations).
- Seven WUs plus a Scenario-WU, one PR each, kept every review small; the commonMain/jsMain split let nearly all web logic (WebGame, LineDrag, WrapPositions, Slides, MessageFeed) be unit- and scenario-tested on JVM and Node.
- Headless Chrome over CDP with a throwaway profile gave real smoke tests (drags, slides, prompts, screenshots in every layout and colour scheme) without touching the user's browser.
- The WU7 checklist settled the three revisit decisions: the startup size picker's Cancel, a rejected save name on the status line, and a blank name as Cancel - all confirmed by the user.

**What was hard or surprising**
- The biggest issue: in WU1 the agent opened a PR link with `open`, which landed in the user's main browser (Chrome) full of their own tabs.
- README was missing from the plan's doc list although the ticket added a platform and a run command.
- The ship agent wrote a made-up BACKLOG title on WU2 (`Add web client`), because the ship skill had no rule for an intermediate WU.
- `:web:serve` never rebuilds on change, and running it with `check`/`build` can run the Gradle daemon out of memory, so it was stopped and restarted around every build.
- The look kept improving after the checklist at the user's request (Mordie's highlighted name, a layout jump, chat-like Mordie lines). The first jump fix measured only height with injected text and missed the sideways jump; treated as a one-off, since the user hadn't said which direction.
- Safari shows no leave-site prompt when a tab is closed, only on reload; a Safari limitation, noted in PRODUCT_SPEC.

**What to change**
- The browser rule is a standing constraint in `docs/CONSTRAINTS.md`; FEATURE.md and TROUBLESHOOT.md point to it.
- The plan template has a "Docs to update" section that prompts for README on a new platform or run command.
- The ship skill writes an intermediate WU's In Progress line with the issue's title verbatim.
- `kotlin-js-store/yarn.lock` is marked `linguist-generated` in `.gitattributes`.
- Follow-up GH-124 (label `brief`): a dev server that rebuilds on change and runs alongside builds.
