## Notes

## Debrief summary

### 2026-10-24

**What went well**
- The user's verdict: quick and smooth, nothing to change.
- The ticket body already held the alert table, the impact and both fix routes, so the work went straight to investigation with no `/brief` or `/plan` round.
- Checking how mocha 11 uses each pinned package (only `diff.createPatch` for failure diffs, and `serialize()` only in parallel mode) made the major-version pins safe to take. A deliberately failing assertion covered the one path the passing tests never reach.

**What was hard or surprising**
- The ticket's preferred route was closed: Kotlin 2.4.21 is the newest stable plugin and still bundles mocha 11.7.6, so yarn resolutions were the fix.
- `rootPackageJson` doesn't treat `YarnRootExtension` resolutions as inputs. The first `kotlinUpgradeYarnLock` left the lock unchanged until `rootPackageJson --rerun` regenerated it. The fix: a note in the build-script comment.
- Dismissing the withdrawn `braces` alert (a GitHub write) was blocked by the session's permission check. The user ran the command themselves.
