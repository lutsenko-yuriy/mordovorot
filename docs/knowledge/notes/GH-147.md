# GH-147: Web on phones: fit the whole game on one screen, no scrolling

## Notes

## Debrief summary

### 2026-10-24

**What went well**
- The user was satisfied overall: one production WU, the plan's decisions settled in one pass (the short footer reworded to `v<version> · Based on Loopover by carykh`, pull-to-refresh given up, 16px tile floor, CSS size container queries).
- A headless harness measured 100+ cases (6 phone sizes × boards × mouse/touch, 100px shorter for browser toolbars, an open dialog, the solution screen) plus landscape against master, which stayed pixel-identical.
- The user tried the branch's build on their own iPhone before the PR: portrait worked; it surfaced landscape scrolling (GH-148) and the wish to block pinch-zoom (GH-149), which led to an accessibility ticket (GH-150). The burger-menu idea was deferred to a `/brief` after GH-147.
- The audit caught the toolbar running past the edge under ~300px (Galaxy Fold cover screen, zoomed pages) once wrapping was turned off; fixed by wrapping again there.

**What was hard or surprising**
- Headless Chrome's `--virtual-time-budget` hangs once a game starts, because Mordie's background search keeps virtual time busy; measuring needed real time and results POSTed back to a small server.
- No recorded way to emulate a touch screen headless: forcing the `pointer: coarse` rules on in a copy of the stylesheet stood in for it.
- The solution screen only opens after Mordie's 5-shift check reveals its solution, so the harness has to shift first.
- Auto mode blocks the agent from serving to the local network; the user ran the server themselves with `!`.

**What to change**
- Web layout changes on phones get a pre-PR check on the user's own phone, via `scripts/web/phone_fit/serve_lan.sh` run by the user (`FEATURE.md` step 10.0).
- The headless harness is kept as `scripts/web/phone_fit/` (`measure.sh`, README) for GH-148 and later layout work.
- Follow-ups: `styles.css` (649 lines) split into dialogs/solution stylesheets; the Dependabot lockfile refresh (body-parser, fast-uri) parked during GH-147.
