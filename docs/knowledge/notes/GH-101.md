## Debrief summary

### 2026-10-17

**What went well**
- The end result was good: one WU, mouse mode untouched (its tests only needed the new `shiftLeft(row, key)` signature), and the review + audit findings were small (a helper moved into `LineSelection`, one missing cross-mode-switch test, one analytics doc sentence).

- That one-number-or-two choice was already there at the first switching question, where only options on one axis were offered. The existing "option-space breadth" dialog principle covers this; it was applied late, not missing.

**What to change**
