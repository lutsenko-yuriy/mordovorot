# Glossary — Accessibility

Screen-reader and text-size support (web client). Part of the [glossary](../GLOSSARY.md).

| Term | Definition | Code symbol |
|---|---|---|
| Read board | Web client only: a button hidden from sight that screen readers and Tab reach during play; it says the board row by row, then how many tiles are in place (`Row 1: 5, 2, 9, 1. … 3 tiles in place.`); letters are said in the phonetic alphabet (`delta`, `bravo charlie`) (GH-167) | — |
| System text size | Web client only: the text size the player set outside the game (the browser's font size, Android's text scaling, iOS Dynamic Type). The page's text and tile labels follow it when it is larger than standard, from the next page load; tile labels stop at their tile's size (GH-168) | — |
