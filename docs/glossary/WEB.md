# Glossary — Web

Web client only: the page, its footer, drag, large boards and the public site. Part of the [glossary](../GLOSSARY.md).

| Term | Definition | Code symbol |
|---|---|---|
| Drag | Web client only: pressing on a tile and dragging slides its row (horizontal drag) or column (vertical drag) under the pointer, snapping to whole tiles on release. Each tile of distance is one shift; the whole drag is one move (GH-110) | `LineDrag` |
| Footer | Web client only: one muted line at the bottom of the page with the app version and the Loopover credit (Cary Huang, links to the original and loopover.xyz) (GH-111) | — |
| Guidance panel | Web client only: during the tutorial, the panel that takes the toolbar's place: a speech bubble from Mordie in larger text above `[ Controls ] [ Labels ] [ Skip ]` (a phone: `[ Labels ] [ Skip ]`, as Controls is out of reach on touch). On a computer, steps 1 to 4 add under the text the ways lines (drag, click, keys) for the asked shift (GH-290). It hides, and the toolbar returns, at the tutorial's last step (GH-288) | `guidancePanel`, `TutorialWays` |
| Installed app | Web client only: the game added to a home screen, dock or app list from the browser's own install offer, opening in its own window with its own icon and name `Mordovorot`. It is the same page and offline copy; on iPhone, iPad and Mac (Safari) it keeps its own saves (GH-357) | `manifest.webmanifest` |
| Public site | The web client published on GitHub Pages at `https://lutsenko-yuriy.github.io/mordovorot/`, updated on every merge to `master` whose build and tests pass (GH-111) | — |
| Restart save question | Web client only: the same dialog `Save your game first?` with `The restart replaces the current game.`, always asked before a restart when the game has moves (GH-349) | `WebDialog.RestartSave`, `WebRestartFlows` |
| Replay save question | Web client only: the dialog `Save your game first?` (`The tutorial replaces the current game.`) with `[ Cancel ] [ Don't save ] [ Save ]`, asked before a tutorial replay when the game has unsaved moves; Cancel (and Escape) starts nothing (GH-289) | `WebDialog.ReplaySave` |
| Share link | Web client only: a link to the public site that carries a game's starting board (its original arrangement; the current board when the start is unknown), shown in the Share dialog with a QR code of the same link and a Copy link button. Opening it starts that board as a fresh game with its own Mordie race, replacing the current game, and the link is then cleared from the address bar. It carries no moves, and tile labels only when the Share dialog's toggle is on | `ShareLink`, `BoardLinkFormat` |
| Shared labels | Web client only: the tile labels a share link can carry when the Share dialog's `Include my tile labels` toggle is on (the labels shown on the sender's board). A receiver is asked whether to use them; Yes applies them to that game only and never changes the receiver's preference. Labels that can't be read are ignored | — |
| Shared progress | Web client only: the sender's moves made and whether they solved the board or gave up, which a share link can carry when the Share dialog's `Include my progress` toggle is on. The receiver's Mordie opens with a line about it. Never forwarded: a re-sharer sends their own | `SharedProgress`, `LinkProgress` |
| Tutorial | Web client only: a short guided game Mordie runs on the tutorial board, shown on launch to a player with no saves who hasn't finished or skipped it. Its steps each wait for one asked-for shift (row, wrap-around, move counter, column); other shifts are blocked with a message. It counts as seen once it has ended or been skipped (GH-288) | — |
| Tutorial board | Web client only: the tutorial's fixed 4x4 game, a few moves from solved, played for real: Moves counts and Mordie races it (GH-288) | — |
| Tutorial button | Web client only: `[ Tutorial ]` (a computer: `[ Tutorial 9 ]`) in the Give Up row, right of `[ Give Up ]` or `[ Mordie's solution ]` and of `[ Hint ]` (GH-332); replays the tutorial, after a save question when there is unsaved progress. Hidden during the tutorial and on the solution screen (GH-289) | — |
| Tutorial highlight | Web client only: on tutorial steps 1 to 4, the dashed rust outline with a pulsing halo around the row or column the step asks to shift, and on a computer its asked arrow, rust and ringed (GH-288) | `tutorialHighlight` |
| Tutorial replay | Web client only: playing the tutorial again any time, from `[ Tutorial ]` (digit 9 on a computer) in the Give Up row; with unsaved moves it asks the replay save question first (GH-289) | `WebTutorial.onReplay` |
| Unsaved progress | At least one shift since the last New game, successful save or successful load. The web client asks before the tab is closed or reloaded with it (GH-110) | `UnsavedProgress` |
| Update notice | Web client only: when a new version of the game is ready, the footer's credit text is replaced by `New version available. Update`, `Update` being a bold, underlined link. Clicking it reloads the page to the new version, after a confirmation if there is unsaved progress | `WebUpdateFlows`, `FooterPart.UpdateLink`, `AppUpdates` |
| Very large | Web client only: board sizes 7x7 to 9x9, offered in their own section of the New game dialog under the 3x3 to 6x6 row, with a warning that they are harder to solve and their tiles may be too small to use comfortably. Mordie plays them like any other size (GH-225) | — |
| Web client | The browser version of the game, played with the mouse or, since GH-171, the keyboard, built on the shared modules, with its saves kept in the browser (GH-110) | — |
