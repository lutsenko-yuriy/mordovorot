# Glossary — Controls

Input and display settings of the web client: keyboard layouts, selection, tile labels, language. Part of the [glossary](../GLOSSARY.md).

| Term | Definition | Code symbol |
|---|---|---|
| Controls dialog | The dialog `[ Controls ]` / 6 opens on a computer: picks the keyboard layout and lists the keys of the marked layout. Replaces the mode-switch button (GH-189; built in GH-170, GH-171) | `ControlsDialogUseCase`, `WebControlsDialog` |
| Cyrillic labels | Two Tile labels schemes after Letter pairs (GH-313), Cyrillic letters (`А Б В Г`, the 28 letters without ё, й, ъ, ы, ь; up to 5x5) and Cyrillic letter pairs (`АА АБ`, up to 9x9), shown in every Language. Screen readers say them with the Russian spelling words (`Анна Борис`) | — |
| Greek labels | Planned (GH-322, after GH-323's grouped dialog): two Tile labels schemes after the Cyrillic ones, Greek letters (`Α Β Γ Δ`, the 24 capitals plus the Greek question mark `;` as the 25th label; up to 5x5) and Greek letter pairs (`ΑΑ ΑΒ`, up to 9x9), shown in every Language. Screen readers say them by their Latin-script names (`alpha beta`), the question mark as `Greek question mark`. Saved through the packed format's escape, as Cyrillic labels are | — |
| Key hints | A computer's on-page reminder of the board keys for the active layout, ordered by hand: two lines under the board, the keys above what they do (GH-170, GH-171) | `KeyHints` |
| Keyboard layout | Which hand does which job on a computer: Right-handed (default; WASD select, HJKL/arrows shift) or Left-handed (HJKL/arrows select, WASD shift). Chosen in the Controls dialog, remembered as a preference (GH-189) | `KeyboardLayout`, `KeyboardLayoutPreference` |
| Label group | A collapsible group of Tile labels schemes by alphabet in the Tile labels dialog: Numbers (four schemes), Latin letters, Cyrillic letters, later Greek. One group is open at a time, the one in use first; an open group stacks its single and paired schemes under one another, by name only; a preview strip above the groups shows the marked scheme's first three labels | — |
| Language | Which language the game's texts are in: English, German or Russian. The first visit follows the browser (English for any other), the picker in the top right corner overrides it (a dropdown on a phone, `EN DE RU` toggles on wider pages); remembered as a preference, never stored in saves or share links (GH-275) | `Language`, `LanguagePreference`, `SessionLanguage` |
| Language picker | The control in the page's top right corner that switches the Language: a dropdown (`EN ▾`, a native select) on a phone, three `EN DE RU` toggles on wider pages. It stands outside the game, after its controls and before the footer in Tab order, and is out of reach while a dialog is open (GH-275) | `DomLanguagePicker`, `PickerControl` |
| Line selection | The selected row and selected column of the old keyboard mode, one of them active; WASD selects, HJKL/arrows shift the active line. Its tiles are highlighted (GH-101). Replaced by Selected tile (GH-169; built in GH-170, GH-171) and no longer in the game | — |
| Selected tile | A computer's selection under the shared keyboard scheme: one tile, so a selected row and column at once; WASD move it, HJKL/arrows shift its row (←/→) or column (↑/↓), and it stays put after a shift; its outlines show after a select or shift key and hide after a press on a tile or an arrow (GH-287). Replaces line selection (GH-169; built in GH-170, GH-171) | `TileSelection` |
| System keyboard layout | The layout the player's OS types with (Latin, Ukrainian, Russian, ...). Not the same as the game's Keyboard layout, which is which hand does which job. Any non-Latin one plays by key position | — |
| Tile labels | How tiles are labelled, one of eight schemes: Numbers (default, `1..side²`), Numbers from 0, Pairs (`23`), Pairs from 0 (`12`), Letters (`G`), Letter pairs (`BC`), Cyrillic letters (`Ж`) and Cyrillic letter pairs (`ЖБ`, GH-313). Chosen in the Tile labels dialog; remembered as a preference and stored in saves, a save's labels winning for that game (GH-139); Letters and Cyrillic letters only label up to 5x5 - on 6x6 and larger Numbers stand in and the preference is kept (GH-160) | `TileLabels`, `TileLabelsPreference` |
